# CAN 应用层协议（工业设备模拟器 v1）

总线为经典 CAN、标准 11 位 ID、500 kbit/s、正常模式。多字节数字均为
小端序，每组报文每秒发送一次。

| ID | 字节 | 含义 |
|---|---|---|
| `0x100` | 0..3 | 心跳计数 `uint32` |
| `0x100` | 4..7 | 设备标识 ASCII `F103` |
| `0x101` | 0..1 | 温度 `int16`，单位 0.1 °C |
| `0x101` | 2..3 | 电压 `uint16`，单位 mV |
| `0x101` | 4..5 | 电流 `uint16`，单位 mA |
| `0x101` | 6..7 | 湿度 `uint16`，单位 0.1 %RH |
| `0x102` | 0..1 | 转速 `uint16`，单位 rpm |
| `0x102` | 2..3 | 压力 `uint16`，单位 0.1 kPa |
| `0x102` | 4 | 环境亮度百分比 `uint8`（STM32 A0光敏传感器） |
| `0x102` | 5 | 状态：1=运行，2=报警 |
| `0x102` | 6..7 | 低 16 位运行计数 |
| `0x200` | 0..3 | 报警位；bit0=超温 |
| `0x200` | 4..5 | 故障码；0=无，1=模拟超温 |

NUCLEO-F103RB 蓝色 USER 按钮为测试输入：按住时温度变为 85.0 °C、
状态变为报警且 `0x200` bit0 置位；松开后自动恢复正常。

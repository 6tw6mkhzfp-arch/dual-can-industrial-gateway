# 第一阶段接线与上电检查

适用条件：NUCLEO-F103RB MB1136，引脚以 UM1724 和实物排针编号交叉核对；其他版本重新核对。USB-CAN 的 H/L/GND 按实际说明书命名，本文不猜端子顺序。

2026-10-22 根据用户照片确认板背印有 `MB1136 rev C`。已与 ST 官方 [UM1724 Nucleo-64 手册](https://www.st.com/resource/en/user_manual/um1724-stm32-nucleo64-boards-mb1136-stmicroelectronics.pdf) 的 Figure 13、Table 27 交叉核对：CN7-16 为 +3.3V、CN7-20 为 GND、CN10-12 为 PA12、CN10-14 为 PA11；对应下方逐线表。ST [NUCLEO-F103RB 产品页](https://www.st.com/en/evaluation-tools/nucleo-f103rb.html)提供 MB1136 C03 原理图。照片仅能确认 `rev C`，不能据此确定 C03/C04/C05 子版本；本阶段所用通用排针映射以手册为准。

用户实测 HW-977：模块上电后 3.3V-GND 为 3.26V；全断电后 2kΩ 档 CANH-CANL 显示 `.120`，即约 120Ω，因此当前模块已有终端，不再并联外部 120Ω。读数由用户口述，未保存仪表照片。

卖家[客户资料页](https://www.xinlucity.com/?s=resourcedetail/index/id/160.html)的“实物图”标出 USB-CAN 绿端子从上到下（USB-C 位于左、绿端子在右的摆放方向）为 `G1, L1, H1, G2, L2, H2`；照片中的两只 120R 拨码分别标 `CAN2`（左）、`CAN1`（右）。用户实物与该图外观相似，但仍须核对自身壳体/板上丝印，并在全断电时测 H1-L1 对应开关 ON/OFF 的约 120Ω/开路变化，再接现场线。G1 是 CAN1 现场参考地；不接主机 USB 外壳。

ST 手册的 USB 供电默认配置为 JP1 不装、JP5 置 U5V、JP6 装、CN2 置 NUCLEO，PC 通过板上 ST-LINK 的 CN1 Mini-B USB 给板供电。上电前仍需观察实物跳帽，不按照片推断其当前状态。ST 手册说明 USB 供电时 CN7 的 +3.3V 可作小负载电源输出，但模块接入前需核对实物电流与电压。

## 底板资料更新

已核查 ATK-DLRK3506B V1.0 原理图第 3/4 页，见 [核查报告](review-2026-09-06.md)。12V 电源先测极性和电压，确认与实物插座尺寸匹配后，只接 POWER1/DC-044A；图中 1 脚为正输入路径、2 脚为 GND。供电能力尚未实测。USB-CAN 用 USB-A 转 Type-C 数据线接底板双层 USB-A 任一口。不要改用未知核心板 Type-C 作 host。

J1 测量点：6 脚接黑表笔地，2/4 脚约 5V，1/17 脚约 3.3V。断电夹好绝缘测试引线后再上电，避免表笔滑动短接相邻针；不要用这几个针脚输入 12V。

## 供电与拓扑

```text
已确认尺寸/极性的 12V 电源 → 底板 POWER1 → RK 核心板与既有屏
底板双层 USB-A → USB-A 转 Type-C 数据线 → 隔离 USB-CAN 主机侧
PC USB → Nucleo 的 ST-LINK USB → Nucleo 3V3 → SN65HVD230

USB-CAN CAN1 现场侧 [120Ω ON]
             H ==================== H  SN65HVD230 [120Ω 一只]
             L ==================== L       ↕ TXD/RXD
      CAN1_GND -------------------- GND   STM32F103RB
             H/L 使用同一对双绞线，GND 为另一路参考线
```

两节点分别位于线缆两端，不星形分叉，模块引线尽量短。USB-CAN CAN2 此时不接线、不开接口、终端 OFF。使用 CAN1 现场隔离地，而不是 USB 外壳、屏蔽层或主机地；不要用额外地线跨过 USB-CAN 隔离屏障。若产品没有现场地端子或定义不明，先核对厂商二线连接规范再接；不要自行猜替代接点。Nucleo 的 USB 电源使其与 PC 相连，不能据此宣称整个台架所有节点完全隔离。

Nucleo 默认仅通过 ST-LINK USB 供电，跳帽保持该板手册规定的 USB 供电状态；不再并联外部 5V/12V。RK 使用原来已工作的供电入口，不同时向未知 USB 供电路径反灌。继电器、24V 灯、RTC、风扇等负载阶段器件暂时断开；12V 电源仅在上述核对完成后接 POWER1。若 USB host 电流不足，再按设备额定值采用规范供电的 USB hub。

## 逐线表（全断电接线）

用户照片中的单路模块正面丝印为 `HW-977`，四针从左到右（以蓝色 CAN 螺丝端子朝下时）为 `TX`、`RX`、`GND`、`3.3V`；蓝色端子左为 `CANL`、右为 `CANH`。这些位置由照片可读，背面线路及板载终端尚未确认。TI [SN65HVD230 产品资料](https://www.ti.com/product/SN65HVD230)给出 3.0–3.6V 工作电源范围；模块必须只用 3.3V。先保持 USB-CAN 现场端未接，量模块断电 CANH-CANL 阻值后再决定是否加外部 120Ω；照片上元件外观不足以断定板载终端配置。

| 线号 | 起点 | 终点 | 核对 |
|---|---|---|---|
| P1 | Nucleo CN7-16，+3V3 | 收发模块 VCC/3V3 | 必须为 3.3V 模块电源 |
| P2 | Nucleo CN7-20，GND | 收发模块 GND | 与逻辑信号共地 |
| S1 | Nucleo CN10-12，PA12/CAN_TX | 模块 TXD/D | 控制器输出接收发器输入；不是串口交叉接法 |
| S2 | 模块 RXD/R | Nucleo CN10-14，PA11/CAN_RX | 模块输出接控制器输入 |
| B1 | USB-CAN CAN1_H | 模块 CANH | 双绞线第一芯 |
| B2 | USB-CAN CAN1_L | 模块 CANL | 双绞线第二芯 |
| B3 | USB-CAN CAN1 现场 CAN_GND | 模块 GND | 仅在该端子定义确认后连接 |
| T1 | 模块 CANH | 通过一只 120Ω 接 CANL | 若板载已有 120Ω，就不再外加 |

RS 若已由模块下拉，保留原设计；若悬空且可访问，按 SN65HVD230 手册接地进入高速模式。不得将已被驱动的 RS 强行短接。Vref 不是供电输出，保持不用。排针编号看手册及 Pin 1 标记，不凭板子摆放方向数针。

## 终端配置

| 实验 | USB CAN1 | USB CAN2 | STM32 模块 | 断电 H-L |
|---|---|---|---|---|
| CAN1 ↔ STM32 | ON | OFF/不接 | 一只 120Ω | 约 60Ω |
| CAN2 ↔ STM32（整体断电换线） | OFF/不接 | ON | 一只 120Ω | 约 60Ω |
| CAN1 ↔ CAN2，两端直连，移走 STM32 | ON | ON | 不接 | 约 60Ω |

第三项只用于适配器两个物理通道互测，H-H、L-L，按手册连接两现场参考地；它们此时处于同一总线，不能证明双独立网络的网关转发。不要给同一总线接三只终端（约 40Ω）。单节点加终端也不能提供远端 ACK。

## 万用表检查表

先拔掉 RK、Nucleo、USB-CAN 等所有供电和 USB，确认无电后才用电阻/蜂鸣档。不要在带电电路量电阻。

| 项目 | 操作与预期 | 不满足时 |
|---|---|---|
| 表笔与档位 | 黑 COM，红 VΩ；不插电流孔，不用电流档跨电源 | 先纠正 |
| 独立终端 | 模块断开总线，H-L 约 120Ω；适配器各开关按 ON/OFF 比较 | 查额外板载电阻，避免叠加 |
| 总线终端 | 接好后断电 H-L 目标约 60Ω（例如 54–66Ω，按阻值容差判断） | 约 120Ω 缺一端，约 40Ω 多一端，近 0Ω 短路，开路缺连接 |
| 线序连续性 | H 到 H、L 到 L、参考地到参考地应接近表笔短接读数 | 查端子、断线、接错 |
| 电源与信号短路 | 检查 3V3-GND、H/L 到电源和地是否存在持续近零阻值 | 不上电；电容充电/保护器件可能影响读数，不能用统一蜂鸣阈值认定正常 |
| 单独供电电压 | 先不接收发模块，Nucleo 3V3-GND 约 3.3V；模块工作要求 3.0–3.6V | 超范围不接模块 |
| 极性和负载后电压 | 断电接模块，再测 VCC-GND 正向约 3.3V，无明显跌落/发热 | 立即断电排查 |
| RK 输入 | 底板 V1.0 的 POWER1 名义 12V；对照实物版本/极性，测输入及 J1 的 5V/3V3 | 接口或版本不符时停用本页映射；异常跌落先查供电 |
| CAN 静态读数 | 仅作短路线索，参考各收发器手册；DMM 显示平均值 | 不能用约 2.5V 或 H>L 证明通信正常 |

推荐顺序：核对型号 → 全断电接线/测阻 → 单独核对电源 → 断电接模块 → 上电 MCU → 插 USB-CAN/识别 → 两端设相同 500k、经典 CAN、normal 模式 → 执行收发。热拔插 CAN 不作为第一阶段步骤。任何异常发热、异味、电压塌陷立即断电；本台架只接成品隔离低压电源输出，不操作市电端。

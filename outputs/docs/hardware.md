# 硬件适配清单

“可用”表示用途上适配，尚不代表实物已经测过。

| 硬件 | 结论与使用条件 |
|---|---|
| RK3506B + MIPI 屏 | 已核查 ATK-DLRK3506B V1.0：POWER1 是 12V 输入、双 USB-A 经 CH334R 接上行 USB；实物版本、插头规格和带载余量仍需核对，GPIO 电压域仍需核心板资料。MIPI 不热插拔，不凭屏尺寸猜引脚。 |
| 双隔离 USB-CAN | 提供的 Linux 包经核验只有 x86/x86-64 的 VCI/libusb 库，不能直接用于 RK ARM32，也不自动生成 CAN netdev；需要品牌型号、VID:PID、Linux ARM 支持、现场侧 CAN_GND 定义、隔离结构及外部供电要求。 |
| NUCLEO-F103RB | 一个经典 CAN 2.0 控制器，不支持 CAN FD；通过板上 ST-LINK USB 供电/烧录，需对应接口的数据线。两路测试顺序换线即可；不能同时当两个独立 CAN 节点。 |
| 2 × SN65HVD230 | 每个只是收发器，没有 CAN 控制器，也不隔离；VCC 为 3.3V，禁止接 5V/12V。第一阶段用一个，另一个备用。查板载 120Ω 与 RS 接法。 |
| 5m、0.3mm² 双绞线 | 可做短距离台架 CAN_H/L；截面积不代表 120Ω 特性阻抗，也不等于屏蔽工业 CAN 电缆。先用约 0.5–1m，成功后测 5m；另备参考地导线。 |
| 3 × AC/DC 24V 指示灯 | 12V 不能保证正常点亮，不纳入第一阶段。后续用符合额定要求的隔离 24V DC 电源，或换 12V 灯。不要接到 MCU GPIO。 |
| 四路 5V 光耦继电器 | 线圈需要额定 5V；3.3V 触发兼容性、低/高有效、VCC/JD-VCC 和跳帽必须看实际电路。不能凭“光耦”认定完全隔离。GPIO 只经确认的驱动级控制，线圈不能由 GPIO 供电。 |
| 12V 2A 电源 | 额定上限 24W；底板原理图已确认 12V POWER1 输入，匹配插头尺寸、极性和实物版本后可作候选电源，带载能力尚未验证；不能直接供 5V 继电器或 3.3V 模块。 |
| 5口百兆交换机 + 两根网线 | 网线可用于 RJ45 网络；交换机使用其原配/铭牌电源，不假设支持 12V 或 PoE。网关两网口先放在不同子网，不随意桥接成环。 |
| 端子、电阻包、万用表 | 用于接线和断电检查；终端选实测约 120Ω 电阻，常规台架可用 1/4W；电阻包不一定包含该阻值。 |
| 32GB TF 卡 | 用于备份和固件；先确认分区/镜像要求，保留原卡，写镜像会覆盖目标卡。 |
| DS1302 模块 | 三线接口，非 I²C；芯片可工作于 2.0–5.5V，但模块上拉、电池/充电电路与 RK 引脚电压未知。暂不接；非充电电池不能启用涓流充电。 |
| 风扇 | 先确认 5V/12V/24V、工作和启动电流，再接相应电源；不能从 GPIO 取电。 |

后续可能需要：USB 数据线（Nucleo 按实物版本）、RK USB host 转接线、参考地线、带保险的低压分配端子；驱动确认后再决定是否更换 USB-CAN。继电器阶段需要合适的 5V 电源/降压模块、匹配的逻辑驱动；24V 灯需要独立 24V 供电。两个独立现场总线同时接 MCU 时，需要第二个 CAN 节点或双 CAN 控制器硬件。
